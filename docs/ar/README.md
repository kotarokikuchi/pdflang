# توثيق PDFLang — العربية

دليل كامل للغة `.pdfl` ولأداة سطر الأوامر `pdfl` — الإصدار 0.13.0.

كل مثال في هذا التوثيق شيفرة قابلة للتنفيذ ومشروحة بالتعليقات. إن كنت تستعمل
اللغة لأول مرة فابدأ بدليل الفصل الأول، أما بقية الفصول فمرجعية تُراجَع عند
الحاجة.

> **عن لغة الأداة.** رسائل `pdfl` (التشخيصات والأخطاء ومساعدة سطر الأوامر
> وعناوين التقارير) **بالإنجليزية**، جريًا على عادة أدوات سطر الأوامر. هذا
> التوثيق بالعربية، لكن الفحص الفاشل يعرض شيئًا مثل
> `page 7: 324% ink (limit 300%)`. أما الرسائل التي تكتبها **أنت** في نصوصك
> البرمجية فتظهر كما كتبتها تمامًا، باللغة التي اخترتها.

## البداية في ثلاثين ثانية

أنشئ الملف `my_profile.pdfl`:

```pdfl
// كل نص برمجي مجموعة من الفحوص. الفحص يجمع التدقيقات المترابطة
// ويصبح قسمًا في التقرير.
check "Basic structure" {
  // require: الرسالة تُولَّد تلقائيًا من التعبير نفسه
  require doc.page_count > 0

  // assert: بالرسالة التي تكتبها أنت
  assert doc.title != "", "PDF has no title in its metadata"
}
```

التنفيذ:

```bash
pdfl run my_profile.pdfl document.pdf
```

يخرج التقرير بصيغة JSON على المخرج القياسي. ورمز الخروج يوضح النتيجة:
`0` نجح كل شيء، `1` تحذيرات فقط، `2` أخطاء تدقيق، `3` خطأ نحوي.

## أعراف هذا التوثيق

- لكل دالة **توقيعها**، وما **تفعله**، وما **تُرجعه**، و**مثال مشروح**.
- الوسائط بين قوسين مربعين اختيارية: `calculate_tac([page])`.
- «ابتداءً من 1» يعني أن الصفحة الأولى هي `1` لا `0` — اللغة تعدّ كما يعدّ
  الناس لا كما يعدّ المبرمجون.
- المقاسات دائمًا بالنقاط (1 pt = 1/72 بوصة). وحروف الوحدات (`3mm` و`1in`) تقوم
  بالتحويل نيابة عنك.
